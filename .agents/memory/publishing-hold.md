## Rule

Keep all changes in the development environment and do not suggest or initiate publishing until the user explicitly says the overall requested work is complete and ready for release.

**Why:** The user wants to finish the full set of requested changes before any production release.

**How to apply:** Continue to build, restart development workflows, and test previews as needed. Treat any eventual release as a separate, explicit user decision.
