## الملخص التنفيذي

RABAB LEGAL AI هي منصة عربية RTL للاستشارات والبحث القانوني وتحليل العقود والمستندات، تابعة لشركة محاماة واستشارات قانونية وتعمل جميع خدماتها تحت إشراف د. رباب أحمد المعبي. جوهر المنتج ليس إجابة آلية منفصلة، بل منظومة قانونية تعتمد على:

- قاعدة معرفة قانونية موثقة ومحددة الدولة.
- بحث دلالي وحرفي مع تحقق من المصادر.
- فصل واضح بين الاستشارة العامة والاستشارة القضائية.
- مسار مستقل للعقود: صياغة، تحليل، واستخراج بيانات.
- سجل جلسات وملفات ومخرجات قابلة للحفظ والتصدير.
- حماية بيانات المستخدم وتطبيق الصلاحيات على الخادم.
- سرية تامة للملفات والمخرجات، وطلب تأكيد المحامية بموافقة صريحة من المستفيد عند الحاجة.
- وحدات خدمات قابلة للتوسع، مع منع تفعيل أي خدمة مستقبلية قبل اعتمادها واختبارها.
- منع ضمان النتائج أو اختلاق المراجع.

## مبدأ التنفيذ الحاكم

يُنفذ العمل على منصة الويب أولاً، مع إبقاء تطبيق الجوال ضمن الخطة منذ البداية. لا تُنقل المزايا إلى الجوال قبل استقرار الـ API والويب واجتياز بوابة الجودة، ثم يُبنى الجوال على نفس الخدمات وقواعد الأمان دون إعادة اختراع المنطق. لا تُعدّل الهوية البصرية أو `index.css` أو الألوان والخطوط المثبتة إلا بطلب صريح.

## الوضع الحالي المختصر

### موجود ومفعّل

- واجهة ويب React/Vite عربية RTL.
- خادم API مبني على Express.
- جلسات دخول وقاعدة PostgreSQL.
- كتالوج خدمات وصفحات مستقلة.
- الاستشارات العامة والقضائية.
- صياغة وتحليل العقود واستخراج بياناتها.
- الباحث القانوني والبحث الموحد والبحث التنظيمي.
- المدونات القضائية والتعاميم وقاعدة المعرفة.
- أرشيف خاص للباحثة الذكية يفصل المصادر والأحكام ويحفظ الأصل والبصمة ومرجع الصفحات قبل إدخالها إلى قائمة المراجعة.
- التحقق من الاقتباسات والتحذير من المصادر غير الموثقة.
- الحصص والباقات والدفع والفواتير.
- الإشعارات والبريد وWhatsApp والبنية الخاصة بالمزامنة.
- لوحة الإدارة وسجلات التدقيق وإدارة المصادر.
- سجل خادمي لوحدات الخدمة ونقطة API آمنة تقرأ حالة الخدمة وقدراتها.

### قيد العمل أو يحتاج استكمالاً

- رفع جودة قاعدة المعرفة والمصادر الرسمية.
- تحسين استئناف السحب من Telegram والمراجعة البشرية قبل الاعتماد.
- تثبيت جودة استخراج النص العربي من الملفات المصورة.
- استكمال اختبارات المسارات المحمية والدفع والحصص.
- تثبيت تجربة الجوال بعد اكتمال أولوية الويب.
- توحيد طبقة رفع الملفات وطلب تأكيد المحامية وتصدير Word في جميع الخدمات النشطة.
- بناء دفعة استيراد معتمدة من أرشيف الباحثة الذكية إلى قاعدة المعرفة، مع منع التكرار والمراجعة البشرية قبل الفهرسة الموثوقة.

### خارج النطاق الحالي

- إدارة مكتب محاماة كاملة.
- توزيع مهام الفرق ومساحات العمل المشتركة.
- استخدام مستندات العملاء لتدريب أي نموذج.
- نشر الإنتاج قبل اعتماد صاحبة المنصة.

## قواعد قراءة الخطة

- كلمة **يجب** تعني شرط قبول لا يُتجاوز.
- كلمة **ينبغي** تعني أولوية تنفيذية قابلة للترتيب.
- حالة **موجود** لا تعني أن الميزة اجتازت كل اختبارات الإنتاج.
- تفاصيل المهام اليومية وملفاتها محفوظة في `.local/tasks/`، وهذه الخطة هي الصورة الموحدة للمشروع وليست بديلاً عن سجل المهام.
