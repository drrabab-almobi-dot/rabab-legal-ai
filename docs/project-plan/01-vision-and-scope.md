# 1. الرؤية والنطاق

## 1.1 الهدف

تقديم مساعد قانوني رقمي عربي يساعد المستخدم على فهم المسألة القانونية، البحث في المصادر، إعداد المسودات، ومراجعة العقود والمستندات، مع إبقاء القرار والمسؤولية المهنية للمحامي المختص.

## 1.2 الفئات المستهدفة

| الفئة | الحاجة الأساسية | مستوى الخدمة |
|---|---|---|
| الأفراد | فهم الحقوق والخطوات والمستندات المطلوبة | الاستشارة القانونية العامة |
| أصحاب الأعمال والمنشآت الصغيرة | صياغة ومراجعة العقود والاستشارات العملية | العقود والاستشارة العامة |
| المحامون والمختصون | تحليل قضائي ودفوع وسوابق ومذكرات | الاستشارة القضائية وإدارة القضية |
| الإدارات القانونية | بحث موثق ومخرجات قابلة للمراجعة | الباحث الذكي والعقود |
| إدارة المنصة | إدارة المستخدمين والباقات والمصادر والجودة | لوحة الإدارة |
| مستخدمو الجوال | الوصول إلى الاستشارات والبحث والملفات والتنبيهات أثناء التنقل | تطبيق الجوال |

## 1.3 النطاق الوظيفي

### داخل النطاق

1. اكتشاف الخدمات بدون إجبار الزائر على تسجيل الدخول.
2. تسجيل الدخول وإنشاء الحساب والتحقق من البريد واستعادة كلمة المرور.
3. تحديد الدولة والاختصاص قبل التحليل.
4. محادثة استشارية مستمرة مع حفظ الجلسة.
5. بحث في المصادر القانونية الرسمية والمصادر المعتمدة.
6. تحليل وصياغة العقود واستخراج بياناتها.
7. إدارة ملفات القضية والجلسات والمذكرات.
8. حفظ النتائج وتصديرها عند توفر الخدمة.
9. الباقات والحصص والدفع والفواتير.
10. إدارة المعرفة والمصادر والمراجعة البشرية من لوحة الإدارة.
11. سجل العمليات والتنبيهات ومراقبة الجودة.
12. تطبيق جوال مرتبط بنفس الحساب والـ API، مع دعم الجلسات والبحث والنتائج والتنبيهات.

### خارج النطاق

- نظام إدارة مكاتب المحاماة.
- اعتماد المستندات أو التوقيع القانوني نيابة عن المستخدم.
- ضمان نتيجة دعوى أو توقع حكم.
- تقديم تمثيل قانوني آلي أمام جهة قضائية.
- تدريب النماذج على بيانات العملاء.
- أي خدمة جديدة لا تعتمدها صاحبة المنصة.

## 1.4 قواعد قانونية ومهنية غير قابلة للتفاوض

- لا اختلاق لمادة أو حكم أو تعميم أو سابقة.
- كل استشهاد يُعرض مع بياناته المتاحة وحالة التحقق.
- لا خلط بين مصادر الدول أو الاختصاصات.
- لا تظهر نقاط القوة والضعف أو الدفوع في الاستشارة العامة.
- لا يُعرض تقدير المركز القانوني إلا في المسارات المسموح بها.
- لا تُعرض نسبة نجاح أو توقع للحكم.
- المذكرات مسودات تحتاج مراجعة واعتماد المحامي.
- كل مخرج يتضمن إخلاء المسؤولية المعتمد.
- بيانات التواصل لا تُحقن داخل مخرجات الخدمات.

## 1.5 مبادئ تجربة المستخدم

- العربية وRTL هما الوضع الأساسي.
- الزائر يفهم الخدمة قبل إنشاء الحساب.
- تسجيل الدخول يظهر عند بدء الخدمة المحمية، مع الحفاظ على مسار العودة.
- كل شاشة خدمة لها عنوان واضح ومسار رجوع مفهوم.
- الإعدادات الاختيارية تبقى مختصرة ولا تستهلك مساحة المنصة.
- لا تُعرض الأقسام الفارغة أو المصطلحات التقنية للمستخدم.
- حالات التحميل والخطأ وانتهاء الحصة واضحة وقابلة للإجراء.

## 1.6 معيار النجاح

يُعد المنتج جاهزاً للمرحلة التالية عندما يستطيع المستخدم:

1. العثور على الخدمة المناسبة دون ارتباك.
2. تسجيل الدخول والعودة إلى الخدمة المطلوبة.
3. تحديد دولته قبل الحصول على تحليل.
4. الحصول على مخرج مفهوم ومحدد المصادر.
5. حفظ النتيجة أو تصديرها حسب صلاحية الباقة.
6. معرفة حدود المخرج وما يحتاج إلى مراجعة بشرية.

## 1.7 نطاق تطبيق الجوال

- تطبيق Expo/React Native للمستخدم النهائي، وليس لوحة الإدارة.
- تسجيل الدخول والتحقق واستعادة الجلسة.
- تصفح الخدمات والباقات وبدء الخدمة المحمية.
- المحادثة والاستشارات مع رفع المرفقات عند دعم المسار.
- البحث القانوني وحفظ النتائج وفتح المصادر.
- عرض جلسات المستخدم ونتائج العقود والفواتير والاستهلاك.
- إشعارات الحصة والاستشارة والاشتراك عند تفعيل الإذن.
- مزامنة الحالة مع الويب عبر API موحد، دون تخزين قانوني حساس في الجهاز إلا عند الحاجة.
- لا يُنفذ الجوال قبل ثبات عقود API وتجربة الويب الأساسية.
