# معاينة تصميم RABAB LEGAL AI لعام 2026

يعتمد هذا الفرع اتجاه **Case Command Center** الذي اختاره مالك المنصة. نُفّذ التصميم فوق المكوّنات والمسارات الحالية، مع الحفاظ على النصوص والأقسام والخدمات في الصفحة الرئيسية وعدم تغيير عقود API أو استهلاك خدمات الذكاء الاصطناعي.

## نطاق التنفيذ

يشمل التنفيذ إطار تنقل جانبيًا لسطح المكتب، ونظام ألوان كحليًا وذهبيًا، وتحديثًا بصريًا للصفحة الرئيسية وصفحتي الاستشارة والعقود، ولوحة حساب جديدة متجاوبة تستعمل بيانات المستخدم الحقيقية. توجد أيضًا صفحة عامة آمنة على المسار `/design-preview` تعرض بيانات تجريبية فقط، ولا تقرأ أي بيانات حساب أو تستدعي خدمة مدفوعة.

## الرجوع

هذا العمل موجود في فرع مستقل ولا يغيّر `main` تلقائيًا. يمكن رفض طلب الدمج أو حذف الفرع للرجوع بلا أي أثر. إذا دُمج لاحقًا ثم تقرر الرجوع، فيُستخدم `git revert` لالتزام الدمج، لأن التنفيذ معزول في ملفات ومكوّنات واضحة ولا يتضمن ترحيل قاعدة بيانات أو تغييرًا لعقود الخدمات.
